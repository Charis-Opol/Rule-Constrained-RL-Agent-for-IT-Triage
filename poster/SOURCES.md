## Build

```bat
poster\build.bat
```

Or by hand, from `poster/`:

```bat
..\.venv\Scripts\python figures\make_simple_flow.py
..\tools\tectonic.exe --only-cached poster.tex
```

Tectonic's package server could not be reached on 14 Nov 2026, so the poster uses only packages that were already cached: `article`, `geometry`, `helvet`, TikZ and `hyperref`. It does not use tikzposter or beamerposter. The four `\DeclareFontShape` lines in the preamble let LaTeX set up its maths fonts at poster sizes from the cached 10 pt files. The poster contains no mathematics. The file also compiles on Overleaf (XeLaTeX or pdfLaTeX).

## Diagram

`figures/simple_flow.svg`, `.png` (300 dpi) and `.pdf` are drawn by `figures/make_simple_flow.py`. The diagram has five boxes in one left-to-right flow, uses plain words with no acronyms, and gives one sentence under each box. Text is white on dark navy or dark red, at contrast above 10:1. At print size, box labels are 40 pt and sentences 27 pt.

The wording differs from the suggested flow where the code does something else:

- No step scores "how clear" a ticket is. A reader picks out the facts, and the agent decides whether to look further.
- The agent's three choices are to run a check, fix, or escalate. "Ask a question" happens only when a check is not in the logs and the operator is asked for it, so the box says "look into it further".
