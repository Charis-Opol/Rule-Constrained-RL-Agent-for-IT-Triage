# Literature

The PDFs of the papers used in the thesis belong in this folder. **They are not in the repository**, because publishers' copyright does not allow redistribution. Only this README is tracked. Full references are in [`../thesis/citations/references.bib`](../thesis/citations/references.bib).

To rebuild the folder, download each paper from its publisher, arXiv or the DOI given in the bibliography, and save it under the file name below.
